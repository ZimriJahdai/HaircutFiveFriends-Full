# Vista de Citas (Appointments)

## Backend — HaircutFiveFriends (`/appointments`)
- Nuevo endpoint **`GET /appointments/mine`**: lista las citas del cliente autenticado (resuelto por token con `attachClientFromToken` + `requireClientFromToken`). Evita exponer `clientId` en la URL.
  - `src/appointment/appointment.controller.js` → `getMyAppointments`
  - `src/appointment/appointment.routes.js` → ruta `/mine` colocada antes de `/:id`.

## Frontend — HaircutFiveFriendsFrontend (`src/features/appointments/`)
Feature nueva, componentes separados por funcionalidad:
- `constants.js` — estados, metadatos de UI, helpers de fecha (ISO ↔ datetime-local).
- `store/useAppointmentStore.js` — Zustand (fetch admin / fetch mine / create / update / cancel).
- `hooks/` — `useAppointments` (admin, filtro por fecha), `useMyAppointments` (cliente), `useAppointmentResources` (catálogos: servicios/barberos/clientes para el modal).
- `components/` — `AppointmentTable`, `AppointmentModal` (crear/editar, admin), `AppointmentCard` (cliente), `AppointmentStatusBadge`, `AppointmentFilters`, `AppointmentsEmptyState`.
- `pages/` — `AppointmentsAdmin` (`/dashboard/citas`), `AppointmentsClient` (`/client/citas`), `ReservarCita` (`/client/reservar`).
- `shared/api/appointment.js` — cliente API (incluye `getMyAppointments`).
- Rutas conectadas en `app/router/AppRouters.jsx` (antes `/client/reservar` apuntaba a `ProbarCorte`).

### Notas backend
- `createAppointment` para `USER_ROLE` auto-asigna cliente (token) y barbero (aleatorio). Por eso `ReservarCita` solo pide servicio + fecha.
- Validación de solapamiento de barbero ya existe en `middlewares/appointment-validator.js`.
